1. 処理概要
================================================================================

CSVファイルの内容を修正して出力する処理。
重要: 行の順番を変更しないこと。

- 入力ファイル: input\工程マスタ修正前.csv
- 出力ファイル: output\工程マスタ修正後.csv
- 出力形式: 元のCSVに「KTCD修正後」列を追加

================================================================================
2. 処理対象データの構造
================================================================================

CSVカラム構成:
  - HMCD: 品目コード（グループ化キー）
  - SEQ: シーケンス番号
  - KTSEQ: 工程シーケンス番号
  - KTCD: 工程コード
  - KTCD修正後: 修正後の工程コード（新規追加列）

================================================================================
3. 処理ロジック（基本）
================================================================================

3.1 グループ化
  - HMCD列をキーとしてグループ化

3.2 最大KTSEQ行の判定
  - 各HMCDグループ内で、KTSEQが最大の行を特定
  - ただし、以下の行は除外して判定:
    * KTCDが"PL"から始まる行
    * KTCDが"PA"から始まる行

3.3 修正対象行の条件
  以下のすべての条件を満たす行が修正対象:
  - (条件1) KTSEQが最大行より小さい
  - (条件2) KTCDに"9"が含まれる
  - (条件3) KTCDが"PL"から始まらない
  - (条件4) KTCDが"PA"から始まらない

3.4 修正ルール
  - KTCDに含まれる"9"とその右側の文字をすべて削除
  - 削除結果を「KTCD修正後」列に格納

3.5 修正対象外の行
  - 「KTCD修正後」列は空欄のまま

================================================================================
4. 例外処理の詳細
================================================================================

4.1 最大行判定時の除外ルール
  - KTCDが"PL"から始まる行は、最大KTSEQ判定から除外
  - KTCDが"PA"から始まる行は、最大KTSEQ判定から除外

  例: HMCDグループに以下の行がある場合
    KTSEQ=5070, KTCD=QBR
    KTSEQ=5080, KTCD=HOLD
    KTSEQ=5090, KTCD=PL      ← 除外
    KTSEQ=5100, KTCD=YAFIN   ← これが最大行

4.2 修正対象からの除外ルール
  - KTCDが"PL"から始まる行は、KTSEQの位置に関わらず修正対象外
  - KTCDが"PA"から始まる行は、KTSEQの位置に関わらず修正対象外

  例:
    PL9J → 修正対象外（KTCD修正後は空欄）
    PA9T → 修正対象外（KTCD修正後は空欄）
    PL9H → 修正対象外（KTCD修正後は空欄）
    PA9B → 修正対象外（KTCD修正後は空欄）

================================================================================
5. 修正例
================================================================================

5.1 修正される例

  (1) L9G → L
      - "9"とその右側("G")を削除

  (2) MC9G → MC
      - "9"とその右側("G")を削除

  (3) TH9R → TH
      - "9"とその右側("R")を削除

  (4) LM9D → LM
      - "9"とその右側("D")を削除

  (5) MC9B → MC
      - "9"とその右側("B")を削除

5.2 修正されない例（空欄）

  (1) PL9J → （空欄）
      - PLから始まるため対象外

  (2) PA9T → （空欄）
      - PAから始まるため対象外

  (3) YAFIN → （空欄）
      - "9"が含まれないため対象外

  (4) 最大行のKTCD → （空欄）
      - 最大行は修正対象外

================================================================================
6. 具体的な処理フロー例
================================================================================

例: HMCD="1151-406CA44"の場合

元データ:
  KTSEQ=5010, KTCD=MC9G
  KTSEQ=5020, KTCD=L9G
  KTSEQ=5030, KTCD=L9G
  KTSEQ=5040, KTCD=TH9G  ← 最大行

処理:
  1. 最大KTSEQ判定: KTSEQ=5040 (TH9G)
  2. 修正対象行: KTSEQ < 5040 かつ "9"を含む行
     - KTSEQ=5010, MC9G → MC
     - KTSEQ=5020, L9G → L
     - KTSEQ=5030, L9G → L
  3. KTSEQ=5040 (最大行) は修正対象外

結果:
  KTSEQ=5010, KTCD=MC9G, KTCD修正後=MC
  KTSEQ=5020, KTCD=L9G, KTCD修正後=L
  KTSEQ=5030, KTCD=L9G, KTCD修正後=L
  KTSEQ=5040, KTCD=TH9G, KTCD修正後=（空欄）
