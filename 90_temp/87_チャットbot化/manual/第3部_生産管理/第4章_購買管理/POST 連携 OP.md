# POST 連携 OP（P734）
<!-- P734 img=1 -->
POST 連携 OP

POST 連携はオプション機能です。
rBOM の見積依頼と発注をEDI システム(POST)と連携するための機能です。
EDI システム(POST)に渡すためのCSV ファイルと帳票のPDF ファイルを作成することができます。
事前に仕入取引先マスタにて、POST 連携するか否かを設定しておきます。

また、EDI システム(POST)から受け取った納期回答をバッチにて取り込むことができます。

※各出力ファイルのパスは『システム管理』の「POST 管理マスタ」にて設定します。
