# 課題No.381 Oracle Base Database Service (BaseDB) - Oracle Database、Grid Infrastructure - 2026年7月 月次推奨パッチ (MRP) 更新

## 内容

メール「Oracle Base Database Service (BaseDB) for fukuharaseiki : [505761ba]」(7/22(水) 7:42)

急速に台頭するAIを活用したサイバーセキュリティ脅威からお客様を保護するため、OracleはOracle Database Security MOS Note PNEWS3015でセキュリティガイダンスを更新しました。Oracleは、お客様がデータベース環境に最新の四半期リリースアップデート（RU）を適用することを推奨します。

さらに、Oracleは月次推奨パッチ（MRP）を提供しています。これは、Oracle Database製品の安定性、セキュリティ、およびパフォーマンスを向上させる、十分にテストされた推奨修正プログラムをより頻繁に利用できるようにしたものです。詳細については、「月次推奨パッチ（MRP）の概要」およびFAQ（FAQ2283）を参照してください。Oracleは、これらのMOSノートを確認し、速やかに対応することを強く推奨します。
