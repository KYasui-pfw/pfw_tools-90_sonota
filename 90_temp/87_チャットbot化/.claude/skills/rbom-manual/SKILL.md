# rBOM操作説明書の検索

マニュアル全体（約80万文字）は大きすぎて一度に読めない。機能単位に分割済みなので、**必要な機能のファイルだけを読む**こと。

## 最初にやること: マニュアルの場所を探す

分割済みマニュアルは、**`manual/INDEX.md` があるフォルダ**。
- 作業フォルダ（Claude Code）または接続したフォルダ（Cowork）の直下にある `manual/` を、まず確認する。
- 無ければ、ファイル検索で `**/manual/INDEX.md` を探す。
- 見つからなければ、推測で答えず「マニュアルのフォルダ（manual/）が見つからない。作業フォルダかフォルダ接続を確認してほしい」と伝える。

以降の `manual/` はこのフォルダを指す。元PDF `V4.0_rBOM操作説明書.pdf` は、`manual/` と同じ階層にある場合がある（無くても検索・回答はできる）。

## 手順

1. **候補を絞る**（全文は読まない）
   - 機能名が分かる → `manual/INDEX.md`（部・章の一覧）→ 該当章の `_INDEX.md`（機能名・ページ・要約・キーワード）の順に見る。
   - 機能名が分からない → `manual/` 全体をgrep（文字列検索）する。質問の言葉をそのまま使わず、言い換えも併せて検索すること（例: 納期変更 → 納期|希望納期|日程変更、取消 → 取消|削除|キャンセル）。まず該当ファイル名と件数だけを見て、当たり過ぎる語は絞る。
   - 章の `_INDEX.md` の要約・キーワードも、候補選びに使う。
2. **該当する機能ファイルだけを読む**
   - 1ファイルが数万文字のものもある（手配指示入力・発注登録・品目マスタなど）。大きいファイルは行番号つきで検索し、必要な範囲だけ読む。
3. **参照先をたどる**
   - 本文中の「※詳細は『第3部 生産管理 第4章 購買管理 [11-02]発注登録』を参照」は、その機能のファイルへ移動する指示。回答に必要な場合だけたどる。
4. **回答する**
   - 手順・項目の意味はマニュアルの記述に沿って答え、**出典（機能名とPDFページ、例: 「受注手配指示入力 P184-188」）を付ける**。
   - マニュアルに書かれていないことは、推測で補わず「マニュアルには記載がない」と伝える。一般知識を足す場合は、そう分かるように区別する。
   - 自社の運用（社内のカスタマイズ・独自ツール等）はこのマニュアルの対象外。

## 画面図が必要なとき

本文はテキストのみ。画面レイアウトやボタン配置を確認したい場合は、ファイル冒頭の「PDFページ」または本文中の `<!-- P184 img=3 -->`（ページ番号と画像数）から、元PDFの該当ページを特定する。
- PDFが手元にあり、ページ単位で読める手段があれば、必要なページだけを読む（数ページずつ。全体は読まない）。
- 読めない・PDFが無い場合は、**ページ番号を伝えて、利用者に原本のそのページを開いてもらう**。

## 注意

- 本文は文字を正規化済み（半角カナ→全角、⽀・⼿などの康熙部首→通常の漢字）。検索は通常の漢字で書く。
- 機能名の `OP` はオプション機能（契約外だと画面がない）。
- 「章の扉」ページ（部・章のタイトルだけのページ）は分割データに含めていない。
- 分割・索引の作り直しは、元の開発フォルダにある `build_manual.py` で行う（管理者の作業。このskillの利用には不要）。
