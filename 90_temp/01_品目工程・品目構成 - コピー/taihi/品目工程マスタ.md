# 品目工程マスタ作成処理（03_create_item_process_master.py）

## 概要
このスクリプトは、`01_integrated_process.py`で作成された`14_品目工程work.csv`を読み込み、**M0840品目工程マスタ**の標準レイアウトに変換してCSV出力する処理です。EJシステム（Oracle Database）から関連データを取得し、工程マスタとの突合も行います。

## 処理の詳細

### 1. 初期設定

**ディレクトリ構成**:
- **入力**: `C:\Dev\90_tools\90_temp\01_品目工程・品目構成\work\14_品目工程work.csv`
- **工程マスタ**: `C:\Dev\90_tools\90_temp\01_品目工程・品目構成\input\M0410_工程マスタ.csv`
- **出力**: `C:\Dev\90_tools\90_temp\01_品目工程・品目構成\output\M0840_品目工程マスタ.csv`

**データベース接続**:
- **EJシステム（Oracle）**: `EXPJ2/EXPJ2@172.17.107.102:1521/EXPJ`
- **使用テーブル**: `M_PUCH_UNIT_COST`, `M_ITEM`

### 2. 工程マスタとの突合

**M0410工程マスタ読み込み**:
- 有効工程コード（KTCD）の一覧を作成
- 工程コード存在チェック用（現在はコメントアウト）

### 3. EJシステムからの関連データ取得

#### 3.1 仕入先・購入単価データ（M_PUCH_UNIT_COST）

**取得SQL**:
```sql
SELECT ITEM_CD, VEND_CD, UNIT_COST, EFF_PHASE_IN_DATE
FROM EXPJ2.M_PUCH_UNIT_COST
ORDER BY ITEM_CD, EFF_PHASE_IN_DATE DESC
```

**処理内容**:
- 最新日付（EFF_PHASE_IN_DATE）優先で辞書作成
- **SRCD辞書**: ITEM_CD → VEND_CD（仕入先コード）
- **SRPRICE辞書**: ITEM_CD → UNIT_COST（購入単価）

#### 3.2 リードタイムデータ（M_ITEM）

**取得SQL**:
```sql
SELECT ITEM_CD, PUCH_FIXED_LT
FROM EXPJ2.M_ITEM
```

**処理内容**:
- **LDTIME辞書**: ITEM_CD → PUCH_FIXED_LT（購入固定リードタイム）

### 4. M0840レイアウトへの変換

#### 4.1 グループ化とシーケンス付与

**処理方法**:
```python
# 完成部番でグループ化
for hmcd, group in df.groupby('完成部番'):
    for idx, row in enumerate(group.iterrows(), 1):
        SEQ = idx        # 1, 2, 3, ...
        KTSEQ = idx * 10 # 10, 20, 30, ...
```

#### 4.2 工程コード（KTCD）抽出・変換

**抽出ロジック**:
```python
# 前工程から最初のハイフンまでを抽出
if '-' in zenkatei:
    ktcd = zenkatei.split('-')[0]
else:
    ktcd = zenkatei  # ハイフンがない場合はそのまま
```

**工程コード変換**:
```python
if ktcd == "A0":
    ktcd = "AO"
elif ktcd in ["PA1", "PA2"]:
    ktcd = "PA"
```

#### 4.3 データベース突合

**キー対応**:
- **SRCD/SRPRICE**: 前工程（完全一致）をキーとしてM_PUCH_UNIT_COSTから取得
- **LDTIME**: 完成部番をキーとしてM_ITEMから取得

### 5. 例外処理

#### 5.1 処理対象外品目

```python
# 特定品目は処理をスキップ
if str(hmcd) in ['KS91-03006BA', 'KD64-00202BA']:
    continue
```

#### 5.2 PEFIN工程の特別処理

**条件**: `KTCD == 'PEFIN'`

**特別設定値**:
```python
LDTIME = 0        # 固定で0
SRPRICE = 0.0     # 固定で0
CSBCD = '10'      # 通常は'13'
RCVTSTKBN = '2'   # 通常は'1'
RCVCHKKBN = '2'   # 通常は'1'
```

### 6. フィールドマッピング

| M0840フィールド | データソース | 説明 |
|-----------------|--------------|------|
| **HMCD** | 完成部番 | 品目コード |
| **SEQ** | 自動連番 | 同一HMCDで1単位連番 |
| **KTSEQ** | 自動連番 | 同一HMCDで10単位連番 |
| **KTCD** | 前工程（変換後） | 工程コード |
| **SRCD** | M_PUCH_UNIT_COST.VEND_CD | 仕入先コード |
| **SRPRICE** | M_PUCH_UNIT_COST.UNIT_COST | 購入単価 |
| **LDTIME** | M_ITEM.PUCH_FIXED_LT | リードタイム |

#### 固定値・条件値

| フィールド | 設定値 | 説明 |
|------------|--------|------|
| **SGNCD** | 空欄 | 作業者コード |
| **SUPCD** | 空欄 | 協力会社コード |
| **DDTIME** | 0 | 段取時間 |
| **SGTIME** | 0 | 作業時間 |
| **CSBCD** | '13' (PEFIN時'10') | 原価区分コード |
| **SUPCLSCD** | 条件値 | 協力会社区分コード |
| **RCVTSTKBN** | '1' (PEFIN時'2') | 入荷検査区分 |
| **RCVCHKKBN** | '1' (PEFIN時'2') | 入荷確認区分 |

#### SUPCLSCD条件値設定

```python
# KTCDがAO（AO（無）を含む）の場合は"6"、それ以外は"5"
supclscd_value = '6' if ktcd.startswith('AO') else '5'
```

### 7. 出力処理

**CSV出力**:
- UTF-8 with BOMエンコーディング
- ヘッダー付き
- `M0840_品目工程マスタ.csv`として出力

**出力確認機能**:
1. **データサンプル表示**: 最初の10行を表形式で表示
2. **フィールドマッピング確認**: 各フィールドの対応関係表示
3. **処理統計**: 品目数、工程数、HMCDごとの工程数（上位10件）

## M0840品目工程マスタの全フィールド定義

| フィールド名 | データ型 | 説明 | 設定値 |
|-------------|---------|------|--------|
| HMCD | 文字列 | 品目コード | 完成部番 |
| SEQ | 数値 | 番号 | 同一HMCD内連番（1単位） |
| KTSEQ | 数値 | 工順 | 同一HMCD内連番（10単位） |
| KTCD | 文字列 | 工程コード | 前工程から抽出・変換 |
| SRCD | 文字列 | 仕入先コード | EJ M_PUCH_UNIT_COST.VEND_CD |

| DDTIME | 数値 | 段取時間 | 0（固定） |
| SGTIME | 数値 | 作業時間 | 0（固定） |
| LDTIME | 数値 | リードタイム | EJ M_ITEM.PUCH_FIXED_LT |
| SRPRICE | 数値 | 購入単価 | EJ M_PUCH_UNIT_COST.UNIT_COST |
| CSBCD | 文字列 | 原価区分コード | '13'（PEFIN時'10'） |

| SUPCD | 文字列 | 協力会社コード | 空欄 |
