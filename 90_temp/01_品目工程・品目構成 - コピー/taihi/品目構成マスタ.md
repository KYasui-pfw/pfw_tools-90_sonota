# 品目構成マスタ作成処理（02_create_item_composition_master.py）

## 概要
このスクリプトは、`01_integrated_process.py`で作成された`13_品目構成work.csv`を読み込み、**M0850品目構成マスタ**の標準レイアウトに変換してCSV出力する処理です。

## 処理の詳細

### 1. 初期設定

**ディレクトリ構成**:
- **入力**: `C:\Dev\90_tools\90_temp\01_品目工程・品目構成\work\13_品目構成work.csv`
- **出力**: `C:\Dev\90_tools\90_temp\01_品目工程・品目構成\output\M0850_品目構成マスタ.csv`

**データ読み込み**:
- UTF-8 with BOMエンコーディングで読み込み
- pandasでDataFrame形式に変換

### 2. M0850レイアウトへの変換

**フィールドマッピング**（指示5に従って）:

| M0850フィールド | データソース | 説明 |
|-----------------|--------------|------|
| **OYAHMCD** | 完成部番 | 親品目コード |
| **KOHMCD** | 前工程 | 子品目コード |
| **KOQTY** | 単位数分子 | 子品目数量 |
| **OYAQTY** | 単位数分母 | 親品目数量 |

**固定値設定**:
```python
SEQ = 1          # シーケンス番号
STRNO = 1        # 構造番号
OYAREVNO = 1     # 親品目改訂番号
STRSEQ = 1       # 構造シーケンス
SHAPEQTY = 1     # 図面数量
OYAQTYKBN = 1    # 親品目数量区分
HASUKBN = 1      # 端数区分
VALFLG = 1       # 有効フラグ
VALDEC = 0       # 値小数点以下桁数
```

**固定文字列**:
```python
OYAUNIT = "PC"   # 親品目単位
KOUNIT = "PC"    # 子品目単位
```

**空欄項目**:
```python
SIZEX = ""       # サイズX
SIZEY = ""       # サイズY
SIZEZ = ""       # サイズZ
NOTE = ""        # 備考
REVNOTE = ""     # 改訂備考
REVDT = ""       # 改訂日
REVTANCD = ""    # 改訂担当者コード
```

### 3. データ変換処理

**行ごとの処理**:
1. **NULL値処理**: `pd.notna()`でNaN値をチェック
2. **型変換**:
   - 文字列項目: `str()`で文字列変換
   - 数値項目: `float()`で浮動小数点変換
3. **デフォルト値**: データが欠損している場合の代替値設定
   - 文字列: 空文字`''`
   - 数値: `1.0`

### 4. 出力処理

**CSV出力**:
- UTF-8 with BOMエンコーディング
- ヘッダー付き（`index=False`でインデックス列は出力しない）
- `M0850_品目構成マスタ.csv`として出力

**出力確認機能**:
1. **データサンプル表示**: 最初の5行を表形式で表示
2. **マッピング確認**: フィールド対応関係の表示
3. **設定値確認**: 固定値・空欄項目の一覧表示

## 重要な設計ポイント

### 1. データ完全性の確保
- NULL値やNaN値に対する適切なデフォルト値設定
- 数値型フィールドの型変換エラー対策

### 2. M0850標準レイアウト準拠
- rBOMシステムが期待する正確なフィールド名・データ型
- 製造業標準の品目構成マスタ形式

### 3. トレーサビリティ
- 変換前後のデータ件数表示
- フィールドマッピングの明示的な確認表示
- サンプルデータの可視化

## 処理結果

この変換により、製造現場で使用される前工程データが、rBOMシステムで標準的に利用される**品目構成マスタ（M0850）**形式に正確に変換されます。

変換されたデータは、部品の親子関係と必要数量を定義し、製造計画や在庫管理システムで活用されます。
