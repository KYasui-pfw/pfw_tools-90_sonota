# 品目構成マスタ (M0850)

## テーブル概要
品目構成を定義するマスタ。品物マスタに登録がある場合は品目定番管理マスタの登録が必須。
※項目は全て品目登録必須。

## テーブル定義

| 項目名 | 物理名 | データ型 | 必須 | 初期値 | 説明 |
|--------|--------|----------|------|--------|------|
| 親品目コード | OYAHMCD | X(30) | ○ | - | 各品目のコード（ユニット等を指定） |
| SEQ | SEQ | 9(5) | ○ | - | 親品目コード単位に1から採番で設定する |
| 図番 | STRNO | X(4) | ○ | - | 図面番号を入力する。リストで使用される |
| 親図版番号 | OYAREVNO | 9(4) | ○ | - | 1セット単位。図面番号と同じ、各品目の構造として登録する品目のコード |
| 構造順序 | STRSEQ | 9(5) | ○ | - | 図面版別番号を入力する。通常は番号と同じ |
| 子品目コード | KOHMCD | X(30) | ○ | - | 各品目の構造として登録する品目のコード |
| サイズX | SIZEX | 9(9,3) | - | - | 鋳物の有品目の場合に鋳物サイズを入力する |
| サイズＹ | SIZEY | 9(9,3) | - | - | 形状のある品目の場合に形状サイズを入力する |
| サイズZ | SIZEZ | 9(9,3) | - | - | 鋳物の有品目の場合に鋳物サイズを入力する |
| 形量 | SHAPEQTY | 9(10,3) | ○ | - | サイズ_X、乙、Zを掛け合わせた値を設定する |
| 親量区分 | OYAQTYKBN | 9(1) | ○ | - | 1:各出品目の個数が必要で計算される、2:各出品目の個数が必要で計算されない |
| 親品目数量 | OYAQTY | 9(11,2) | ○ | - | 通常1セット、各回に対しての製品を入力する場合にのみ1以外を設定する |
| 親品目単位コード | OYAUNIT | X(3) | ○ | - | 単位マスタ必須設定 |
| 子品目数量 | KOQTY | 9(11,2) | ○ | - | 各単位に対する子品目製品（構造品）数量 |
| 子品目単位コード | KOUNIT | X(3) | ○ | - | 単位マスタ必須設定 |
| 有効小数点数 | VALDEC | 9(1) | ○ | - | 必要で計算の際に除算が行われる場合に小数点桁数を決めて計算するかの設定。通常の場合はO |
| 端数処理区分 | HASUKBN | X(1) | ○ | - | 除算が行われる場合の端数処理方法：1:人の切り上げ、2:切り捨て、3:切り捨げ |
| 備考 | NOTE | X(100) | - | - | 基本的に何かを入力しない |
| 改訂備考 | REVNOTE | X(40) | - | - | 登録後も入力しない |
| 改訂日 | REVDT | DATE | - | - | 登録後も入力しない |
| 改訂責任者コード | REVTANCD | X(8) | - | - | 全般1を設定 |
| 有効フラグ | VALFLG | 9(1) | ○ | - | 1,2 |

## データ制約

### 設定可能値
- OYAQTYKBN: 1,2
- VALDEC: 0,1,2,3,4,5,6
- HASUKBN: 1,2,3
- VALFLG: 1,2

### チェック区分
- 1,2: 利用、配布
- 1,3,4: 利用

### 参照マスタ
- 53_品目マスタ(M0810),B (OYAHMCD, KOHMCD)
- 13_単位マスタ(S0910),B (OYAUNIT, KOUNIT)
- 8_社員マスタ(M0540),B (REVTANCD)

### 使用状態
- 利用: OYAHMCD, SEQ, STRNO, OYAREVNO, STRSEQ, KOHMCD, SIZEX, SIZEY, SIZEZ, SHAPEQTY, OYAQTYKBN, OYAQTY, OYAUNIT, KOQTY, KOUNIT, VALDEC, HASUKBN, REVTANCD, VALFLG
- 日付: REVDT
- 未使用: NOTE, REVNOTE
