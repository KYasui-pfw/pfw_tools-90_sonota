# 品目工程マスタ (M0840)

## テーブル概要
品目工程を定義するマスタ。

## テーブル定義

| 項目名 | 物理名 | データ型 | 必須 | 初期値 | 説明 |
|--------|--------|----------|------|--------|------|
| 品目コード | HMCD | X(30) | ○ | - | 品目マスタに設定した品目コード |
| 順番 | SEQ | 9(4) | ○ | - | 品目コード単位に1から採番で設定 |
| 工順 | KTSEQ | 9(4) | ○ | - | 品目コード単位に工程の順番を入力する |
| 工程コード | KTCD | X(5) | ○ | - | 工程マスタ必須設定。製造品目に属付ける工程のコードを設定 |
| 仕入先コード | SRCD | X(10) | - | - | 仕入取引先マスタ先行設定要。社内工程の場合、自社部門などを仕入先として登録する |
| 資源コード | SGNCD | X(5) | - | - | 資源マスタ先行設定要。社内工程で使用する資源コード |
| 段取時間 | DDTIME | 9(4) | ○ | - | 社内工程の段取時間。未設定時は0をセット（単位：分） |
| 作業時間 | SGTIME | 9(4) | ○ | - | 社内工程の作業時間。未設定時は0をセット（単位：分） |
| リードタイム | LDTIME | 9(3) | ○ | - | 未設定時は0をセット（単位：日） |
| 仕入単価 | SRPRICE | 9(10,2) | ○ | - | 社外工程を発注する際のデフォルト単価。未設定時は0をセット |
| 原価科目コード | CSBCD | X(10) | - | - | 原価科目マスタ先行設定要。[原価科目M：内外区分]と[仕入取引先M：仕入先区分]を合わせる |
| 調達区分コード | SUPCLSCD | X(2) | - | - | 調達区分マスタ先行設定要 |
| 調達部門コード | SUPCD | X(2) | - | - | 調達部門マスタ先行設定要 |
| 受入検査区分 | RCVTSTKBN | 9(1) | ○ | - | 1：あり、2：なし。発注登録で該当品目設定時に検査有無をデフォルト設定する |
| 受入検収区分 | RCVCHKKBN | 9(1) | ○ | - | 1：あり、2：なし。発注登録で該当品目設定時に検収有無をデフォルト設定する |

## データ制約

### 設定可能値
- RCVTSTKBN: 1,2
- RCVCHKKBN: 1,2

### チェック区分
- 1,2: 利用、配布

### 参照マスタ
- 53_品目マスタ(M0810),B (HMCD)
- 46_工程マスタ(M0410),B (KTCD)
- 45_仕入取引先マスタ(M0710),Q (SRCD)
- 45_資源MS(M0430),B (SGNCD)
- 26_原価科目マスタ(M0080),B (CSBCD)
- 37_調達区分マスタ(M0360),B (SUPCLSCD)
- 36_調達部門マスタ(M0050),B (SUPCD)

### 使用状態
- 利用: HMCD, SEQ, KTCD, SRCD, SGNCD, DDTIME, SGTIME, LDTIME, SRPRICE, CSBCD, SUPCLSCD, SUPCD, RCVTSTKBN, RCVCHKKBN
- 廃止: KTSEQ
