# EJ-rBOM マッピングツール（シンプル版）

製造業の生産管理システム更新に伴い、旧EJシステムと新rBOMシステムの発注残データをマッピングするStreamlitアプリケーションです。

**本バージョンは自動マッピングと固定機能のみに絞ったシンプル版です。**

## 機能概要

- **自動マッピング**: 品目コードと数量をキーにしたEJ-rBOMデータの自動マッピング
- **マッピング確定**: マッピング結果の確定/解除管理
- **データ表示**: st.data_editorを使用したマッピング結果の一覧表示
- **CSV出力**: マッピング結果のCSVエクスポート

## システム要件

- Python 3.8+
- Oracle Database（EJシステム用）
- インターネット接続（rBOM API用）

## インストール

1. リポジトリのクローンと仮想環境作成
```bash
cd C:\Dev\90_tools\09_EJ_rBOM_マッピング２
python -m venv venv
```

2. 仮想環境の有効化とライブラリインストール
```bash
# Windows
.\venv\Scripts\activate

# パッケージインストール
pip install -r requirements.txt
```

3. 環境変数設定
```bash
# .env.exampleをコピーして.envを作成
copy .env.example .env

# 必要に応じて.envファイルを編集
```

## 使用方法

1. アプリケーション起動
```bash
streamlit run 発注残マッピングリスト.py
```

2. ブラウザで`http://localhost:8501`にアクセス

3. 抽出条件を設定（納期は2025年11月1日以降）

4. 「自動マッピング」ボタンをクリック

5. マッピング結果を確認
   - チェックボックスでマッピング確定/解除を選択
   - 「マッピング確定情報更新」ボタンで確定情報を保存

6. 必要に応じてCSV出力

### EJシステム（Oracle Database）
- **接続先**: 172.17.107.102:1521/SN=EXPJ
- **テーブル**: T_RLSD_PUCH_ODR（発注残）+ M_ITEM（品目マスタ）
- **制限**: 納期2025年11月1日以降のデータのみ（データ量削減のため）

### rBOMシステム（API）
- **URL**: http://pfw-api/orders/
- **認証**: READ_API_KEY="oG5^Ls%#20yq"

## マッピングロジック

1. **固定マッピング除外**: 固定済みマッピングを除外
2. **自動マッピング**: 品目コード + 数量が完全一致するデータをマッピング
3. **未マッチデータ**: EJのみ、rBOMのみのデータも表示

- **データ量制限**: EJシステムのデータ量を考慮し、納期は2025年11月1日以降のみ対応
