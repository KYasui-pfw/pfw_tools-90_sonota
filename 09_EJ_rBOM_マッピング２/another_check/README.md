# 前工程一致抽出ツール

## 概要

EJシステムの発注残データと、前工程.csvの品目コードを照合し、一致したデータを抽出するツールです。

## ディレクトリ構造

```
another_check/
├── input/
│   └── 前工程.csv          # 入力ファイル（品目コードリスト）
├── output/
│   └── 前工程_EJ発注残_一致.csv  # 出力ファイル（自動生成）
├── logs/
│   └── 前工程一致抽出_YYYYMMDD.log  # 実行ログ（自動生成）
├── 前工程一致抽出.py      # メインスクリプト
└── README.md              # このファイル
```

## 前提条件

- Python 3.8以上
- 必要なライブラリ（親ディレクトリのrequirements.txtに記載）
  - pandas
  - oracledb
  - python-dotenv

## 使用方法

### 1. 入力ファイルの配置

`input/前工程.csv` に品目コードリストを配置してください。

**CSVフォーマット:**
- ヘッダーなし
- 1列のみ（品目コード）
- 文字コード: UTF-8

**例:**
```
PL-00-1153AA
MC-00-1157AA
PA-00-757B
```

### 2. スクリプトの実行

```bash
# 仮想環境がある場合は有効化
cd C:\Dev\90_tools\09_EJ_rBOM_マッピング２
venv\Scripts\activate

# スクリプト実行
cd another_check
python 前工程一致抽出.py
```

### 3. 結果確認

- **出力ファイル**: `output/前工程_EJ発注残_一致.csv`
- **実行ログ**: `logs/前工程一致抽出_YYYYMMDD.log`

## 出力CSVフォーマット

| 列名 | 説明 |
|------|------|
| order_no | EJ発注番号 |
| item_code | 品目コード |
| item_name | 品目名称 |
| quantity | 発注数量 |
| status | ステータス |
| purch_odr_typ | 発注種別 |
| delivery_date | 納期 |
| 前工程 | 前工程品目コード（一致した値） |

## 処理内容

1. **前工程CSV読み込み**
   - `input/前工程.csv`を読み込み
   - 品目コードの前後空白を削除
   - 重複を除去してユニークなセットを作成

2. **EJデータ取得**
   - Oracle DBから発注残データを取得
   - 抽出条件:
     - 納期: 2025-07-01 〜 2027-01-31
     - PUCH_ODR_STS_TYP = 2
     - PUCH_ODR_TYP ≠ 4

3. **照合処理**
   - EJ品目コード（前後空白削除後）と前工程CSVを比較
   - 一致したデータのみ抽出

4. **CSV出力**
   - `output/前工程_EJ発注残_一致.csv`に出力
   - 文字コード: UTF-8 BOM付き（Excel対応）

## トラブルシューティング

### Oracle接続エラー

```
Error: EJシステムからのデータ取得に失敗しました
```

**対処法:**
- Oracle Instant Clientがインストールされているか確認
- ネットワーク接続を確認（EJサーバー: 172.17.107.102:1521）
- 環境変数またはデフォルト接続情報を確認

### ファイルが見つからない

```
FileNotFoundError: 入力ファイルが見つかりません
```

**対処法:**
- `input/前工程.csv`が存在するか確認
- ファイル名が正確か確認（全角・半角に注意）

### 一致データが0件

```
WARNING - 一致するデータがありませんでした
```

**対処法:**
- 前工程.csvの品目コードフォーマットを確認
- EJ発注残データの納期範囲を確認
- ログファイルで詳細を確認

## ログ情報

実行ログには以下の情報が記録されます:

- 処理開始/終了時刻
- 前工程CSV読み込み件数
- EJデータ取得件数
- 一致件数と一致率
- 一致した品目コード別件数（上位10件）
- エラー情報（発生時）

## 注意事項

- EJデータベースへの接続が必要です
- 大量データの場合、処理に時間がかかることがあります
- 出力ファイルは上書きされます
