製番発注_不要発注チェック

検索条件

製番発注のうち、部品表の上では「もう要らない」部品なのに、発注が残っているものを探します。

  1. 製番を選ぶ
    指定した月次（開始～終了）の製番のうち、まだ完了していない製番だけを対象にします。
    製番完了（D3030）にデータがある製番は、完了済みとして除きます。
    在庫発注（ZAIKOSEIBAN）と経費・工具発注（KEIHI）は製番発注ではないため、対象外です。
  2. 部品表の最新版を見る
    対象製番の部品表（D3110）は、改版するたびに同じリスト番号の行が増えていきます。 そのため、リスト番号ごとに訂番がいちばん大きい行（＝最新版）だけを見ます。
  3. 「要らなくなった」部品を拾う
    最新版で次のどちらかに当てはまる部品を拾います。
    • 必要量が 0
    • 有効状態が 無効（部品表から外された部品）
  4. 発注と突き合わせる
    拾った部品のうち、同じ製番・リスト番号の発注明細（D3340）があるものを一覧にします。
    発注の状態（未受入・完納など）では絞り込んでいません。必要に応じて一覧の列フィルターで絞ってください。

月次は「年・月・次」をつなげた数字（例: 2026年11月1次 → 2026111）で範囲を指定します。 空欄にした側は範囲指定なし（両方空欄なら全期間）です。
注文書の「発行済／未発行」は、発注ヘッダ（D3330）の注文書発行区分（2＝発行済、1＝未発行）で表示しています。
