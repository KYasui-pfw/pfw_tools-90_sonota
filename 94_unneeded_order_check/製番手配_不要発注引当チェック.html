製番手配_不要発注引当チェック

検索条件

製番手配のうち、部品表の上では「もう要らない」部品なのに、発注や引当が残っているものを探します。

  1. 製番を選ぶ
    指定した月次（開始～終了）の製番を対象にします。
    製番完了（D3030）にデータがある製番は製番完成済です。「製番完成済を除く」にチェックがあるとき（初期値）は、完成済の製番を除きます。
    在庫発注（ZAIKOSEIBAN）と経費・工具発注（KEIHI）は製番発注ではないため、対象外です。
  2. 部品表の最新版を見る
    対象製番の部品表（D3110）は、改版するたびに同じリスト番号の行が増えていきます。 そのため、リスト番号ごとに訂番がいちばん大きい行（＝最新版）だけを見ます。
  3. 「要らなくなった」部品を拾う
    最新版で次のどちらかに当てはまる部品を拾います。
    • 必要量が 0
    • 有効状態が 無効（部品表から外された部品）
  4. 発注・引当と突き合わせる
    拾った部品のうち、同じ製番・リスト番号の発注明細（D3340）または引当明細（D3520）があるものを一覧にします。 「区分」列で発注／引当を見分けられます。
    発注・引当の状態（未受入・完納など）では絞り込んでいません。必要に応じて一覧の列フィルターで絞ってください。
    「受入/棚出済」は、発注の行では受入数（D3360）、引当の行では棚出数（D3540）の合計です。 引当には注文書・仕入先がないため、その列は空欄になります（引当の「発注/引当日」は引当日、「希望納期/棚出予定日」は棚出予定日）。

月次は「年・月・次」をつなげた数字（例: 2026年11月1次 → 2026111）で範囲を指定します。 空欄にした側は範囲指定なし（両方空欄なら全期間）です。
注文書の「発行済／未発行」は、発注ヘッダ（D3330）の注文書発行区分（2＝発行済、1＝未発行）で表示しています。
「自動発注」は、業務ポータルの注文書自動発行登録にその品目CD＋工程が登録されていれば「有」（発注の行のみ。登録が無ければ空欄）。 「集約注文番号」は、業務ポータルの集約注文書発行のマッピングにその発注（発注番号＋行）があれば集約注文書番号（Dxxxxxxxx。無ければ空欄）です。
