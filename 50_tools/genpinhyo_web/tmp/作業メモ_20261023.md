## 2. 決まったこと（要約。詳細は API 仕様書の2章）
- Django の DB は直接読まず、API で取る。
  - **API はキーレス**（ログインも API キーも不要）。当初はキー（`X-API-KEY`）で守る案だったが、同日に変更した。
- 伝票の VER は、作業計画（加工スケジュール作成）のロット番号（H始まり）で引く。
  - F番号と過去のデータは不要。
  - **`lot_mapping.db` は廃止**する。
- 工程文字列は、品目工程マスタから**連番付き**（`B1-G1-L1-G2`）で組み立てる。
- 工程図は Django の工程図管理を**正**とする。
  - **M は不要。**
  - 使うのは **B1・B2・F1・F2・L・R・C の7つ**。ほかに **手書き（`@`）** と **予備1〜4** を持つ。
  - Django の列は記号ごとに**前詰め**して入れる。あふれた分は B→F→L→R→C の順で予備へ入れる。予備にも入りきらない分は捨てる。
  - 表記は**記号付き**（`TS-5621HA34-F1`）。
  - 品目は**品目CD2 で先に引き、無ければ品目CD** で引く。
