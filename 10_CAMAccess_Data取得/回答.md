# アプリケーション構成提案

## ディレクトリ構造

```
/home/docker-user/docker-apps/8_camcyl_app/
├── Dockerfile              # Python + Java + cron環境
├── docker-compose.yml      # コンテナ定義
├── .env                    # 環境変数（CSVパス、出力先など）
├── requirements.txt        # pandas, JayDeBeApi
├── crontab                 # 15分ごとに処理1と処理2を並列実行
├── scripts/
│   ├── process1.py        # rBOM CSVコピー・加工
│   ├── process2.py        # Access DB → CSV抽出
│   ├── logger_config.py   # ログ設定（7日間ローテーション）
│   └── run_all.sh         # 処理1と処理2を並列実行するラッパー
├── ucanaccess_lib/        # UCanAccess JARファイル群
├── data/                  # Access DBコピー先
└── logs/                  # ログ出力先
```

## ネットワークドライブマウント手順（Linux）

### 手順1: cifsツールのインストール
```bash
sudo apt-get update
sudo apt-get install cifs-utils
```

### 手順2: マウントポイント作成
```bash
sudo mkdir -p /mnt/schejule
```

### 手順3: /etc/fstabに追加（起動時自動マウント）

**認証情報ファイル作成**
```bash
sudo nano /etc/smbcredentials
```

以下を記述：
```
username=ユーザー名
password=パスワード
domain=ドメイン名（あれば）
```

**パーミッション設定**
```bash
sudo chmod 600 /etc/smbcredentials
```

**/etc/fstabに追加**
```bash
sudo nano /etc/fstab
```

以下を追加：
```
//172.17.81.101/schejule /mnt/schejule cifs credentials=/etc/smbcredentials,uid=1000,gid=1000,iocharset=utf8 0 0
```

### 手順4: マウント実行
```bash
sudo mount -a

# 確認
ls /mnt/schejule/cylline
ls /mnt/schejule/camline
```

## docker-compose.ymlでのマウント設定

```yaml
volumes:
  - /mnt/schejule:/mnt/schejule:ro  # 読み取り専用
  - /home/docker-user/rBOM:/app/rBOM:ro
  - /home/docker-user/KakouDenpyo:/app/output/KakouDenpyo
  - /home/docker-user/KakouJisseki:/app/output/KakouJisseki
  - ./data:/app/data
  - ./logs:/app/logs
```

## cron設定（15分ごと並列実行）

```cron
*/15 * * * * /app/scripts/run_all.sh >> /app/logs/cron.log 2>&1
```

## .env設定例

```env
# 処理1: rBOM CSVファイルパス
CSV1_PATH=/app/rBOM/rBOM_bat/PFW_OT/File/KAKOU_EXP/CAM/CAMKakouDenpyou.csv
CSV2_PATH=/app/rBOM/rBOM_bat/PFW_OT/File/KAKOU_EXP/CAM/CONV.csv
CSV3_PATH=/app/rBOM/rBOM_bat/PFW_OT/File/KAKOU_EXP/CAM/SEISANKI.csv
CSV4_PATH=/app/rBOM/rBOM_bat/PFW_OT/File/KAKOU_EXP/M_S/ASPKakouDenpyo.csv

# 処理1: 加工対象ファイル（項目削除・重複削除）
PROCESS_FILE1=CAMKakouDenpyou.csv
PROCESS_FILE2=ASPKakouDenpyo.csv

# 処理1: 削除対象カラム（カンマ区切り、後で設定）
DELETE_COLUMNS_FILE1=
DELETE_COLUMNS_FILE2=

# 処理1: 出力先
OUTPUT_DIR_DENPYO=/app/output/KakouDenpyo

# 処理2: Access DB
ACCDB_SOURCE1=/mnt/schejule/cylline/Cyl_pfw_table.accdb
ACCDB_SOURCE2=/mnt/schejule/camline/EJ/EJ_DETA_SERVER/EJデータマスター.accdb

# 処理2: 抽出テーブル
TABLE1_NAME=KaLstCyl_All
TABLE2_NAME=CAMFIN_LOG_ALL

# 処理2: 出力先
OUTPUT_DIR_JISSEKI=/app/output/KakouJisseki

# ログ設定
LOG_DIR=/app/logs
LOG_RETENTION_DAYS=7
```

## 処理フロー

### 処理1: rBOM CSVコピー・加工
1. 環境変数から4つのCSVファイルパスを読み込み
2. CONV.csv、SEISANKI.csv → そのままコピー
3. CAMKakouDenpyou.csv、ASPKakouDenpyo.csv → 項目削除+重複削除してコピー
4. 全ファイルを `/home/docker-user/KakouDenpyo` に出力

### 処理2: Access DB → CSV抽出
1. `/mnt/schejule/cylline/Cyl_pfw_table.accdb` を `/app/data` にコピー
2. `/mnt/schejule/camline/EJ/EJ_DETA_SERVER/EJデータマスター.accdb` を `/app/data` にコピー
3. UCanAccessで各DBに接続
4. `KaLstCyl_All` テーブルを抽出 → `Cyl_pfw_table_KaLstCyl_All.csv`
5. `CAMFIN_LOG_ALL` テーブルを抽出 → `EJデータマスター_CAMFIN_LOG_ALL.csv`
6. 両ファイルを `/home/docker-user/KakouJisseki` に出力

### 処理3（将来実装）
- `/home/docker-user/KakouJisseki` のCSVをAPIサーバー経由で更新
- 処理2のCSV出力後すぐに実行
